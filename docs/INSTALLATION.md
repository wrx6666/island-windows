# Установка Island

## Приложение

1. В [Releases](https://github.com/wrx6666/island-windows/releases/latest) скачай `IslandSetup.exe`.
2. Запусти файл. Установка выполняется для текущего пользователя; .NET включён в пакет.
3. Открой настройки через шестерёнку внутри острова.

`Source code.zip` — исходники для разработчиков, а `.nupkg` и `releases.win.json` — файлы обновления. Для обычной установки нужен только `IslandSetup.exe`.

## Музыка в браузере

Начиная с 0.11.2 основной режим работает **без расширения**. В **Настройки → Запуск** выбери Яндекс Музыку и Яндекс Браузер, включи **«Запускать сервис по Play»**. Пункт **«Использовать Island Music Bridge»** оставь выключенным.

Войти в музыкальный аккаунт нужно самостоятельно в обычном профиле браузера. Island не переносит пароли или cookies и не создаёт отдельный профиль.

Доступный плеер управляется через медиасессию Windows. Если её ещё нет, Island ищет музыкальную страницу среди открытых вкладок; если не находит — открывает её. Кнопка Play вызывается через Windows UI Automation, затем приложение ждёт подтверждения воспроизведения от Windows. Пустое окно или отправленная команда не считаются успешным запуском.

Сайт должен предоставлять кнопку через интерфейс специальных возможностей Windows. Изменения браузера и сайта могут нарушить обнаружение; холодный запуск в реальном Яндекс Браузере пока не проверен. Если свёрнутый браузер не предоставляет страницу, Island может временно показать его окно без запроса фокуса. Сам браузер может активировать окно при запуске — незаметный запуск поверх игры не гарантируется.

Обложка, трек, перемотка и переключение доступны в объёме, который предоставляет браузер Windows. Громкость меняется для браузера целиком, включая другие вкладки. Если в этом браузере несколько источников звука, Windows не гарантирует выбор именно музыкального сайта. Точная очередь и позиция трека не восстанавливаются; используется доступный сохранённый адрес или главная страница сервиса.

## Дополнительный Music Bridge

Этот режим необязателен. Включи **«Использовать Island Music Bridge»** в настройках запуска, если хочешь получать команды и метаданные непосредственно от музыкальной вкладки. Установщик регистрирует Native Messaging Host; расширение включается вручную:

1. Открой **Настройки Island → Запуск → Папка Music Bridge** (кнопка также есть в разделе «Обновления»).
2. В Яндекс Браузере открой `browser://extensions`, в Chrome — `chrome://extensions`, в Edge — `edge://extensions`.
3. Включи режим разработчика и выбери **«Загрузить распакованное»**.
4. Укажи открывшуюся папку `browser-extension` из установленного Island.
5. Обнови вкладку Яндекс Музыки или VK и проверь подключение в значке Music Bridge.

В музыкальный аккаунт нужно войти в браузере самостоятельно. Начиная с 0.11.1 папка расширения находится вне каталога версии: `%LOCALAPPDATA%/Island.Desktop/browser-extension`. Если раньше расширение подключалось с рабочего стола или из `current`, один раз заново подключи его из постоянной папки. Не удаляй и не переноси эту папку.

## Play после запуска Windows

В **Настройки → Запуск** выбери сервис, браузер и включи **«Запускать сервис по Play»**. До нажатия Play браузер для этого не запускается; автоматическое воспроизведение при входе в Windows остаётся выключенным по умолчанию.

В основном режиме подключение расширения не ожидается: используются Windows и доступная кнопка страницы. В дополнительном режиме Island ждёт Music Bridge. Повторные нажатия объединяются; повторное открытие ограничено паузой 30 секунд. При неудаче приложение сообщает о ней, а не открывает вкладки бесконечно.

Распакованное расширение установлено в режиме разработчика. Яндекс Браузер может отключать расширения из непроверенных источников. Island не изменяет защитные настройки, список разрешений или файлы профиля браузера и не включает расширение скрытно. Для обычной установки без режима разработчика нужен отдельный выпуск Music Bridge в поддерживаемом каталоге расширений; сейчас он не опубликован.

## Автозапуск и клавиши

**Настройки → Запуск** — запуск вместе с Windows. Автоматическое включение музыки — отдельная настройка, выключенная по умолчанию.

**Настройки → Музыка и звук** — клавиши Play / Pause и отключения звука выбранного приложения. Можно использовать одну клавишу или сочетание. Если клавиша занята Windows или другой программой, выбери другую.

## Обновление

Открой **Настройки → Обновления**, нажми **«Проверить обновления»**, затем **«Загрузить и перезапустить»**. Новая версия становится доступна после публикации обычного релиза; черновик не считается опубликованным обновлением.

Для обновления старой сборки, в которой источник GitHub ещё не настроен, один раз установи актуальный `IslandSetup.exe` из этого репозитория.

## Если музыка не подключается

Проверь выбранный браузер, вход в музыкальный аккаунт, интернет и доступность Play на сайте. В основном режиме расширение не требуется. Если Windows не видит плеер, один раз покажи музыкальную страницу и проверь воспроизведение в ней. При блокировке autoplay нажми Play на музыкальном сайте: Island не обходит ограничения браузера.

Только если включён дополнительный Music Bridge: проверь расширение и обнови музыкальную вкладку. После изменения разрешений или файлов расширения перезагрузи его на странице расширений.

## Удаление

Закрой Island и удали его через **Параметры Windows → Приложения → Установленные приложения**. Расширение удаляется отдельно в браузере. Локальные настройки сохраняются, чтобы их можно было восстановить при повторной установке.
